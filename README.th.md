# 🎸 Guitar Stem Studio (ภาษาไทย)

[English](README.md) · **ภาษาไทย**

![Player](docs/images/player.png)

โปรแกรมแยกเสียงดนตรีจาก MP3 (กีตาร์ / เสียงร้อง / กลอง / เบส / เปียโน / อื่นๆ) + ถอดโน้ตกีตาร์เป็น Tab ที่วิ่งตามเพลง
ทำงานบนเครื่องตัวเอง 100% ผ่านหน้าเว็บ (ไม่ต้องอัปโหลดเพลงขึ้นเน็ต)

## ฟีเจอร์
- **วางลิงก์ YouTube** แล้วโหลดเพลงเป็น MP3 ให้อัตโนมัติ (ใช้ yt-dlp + ffmpeg ที่ติดมากับโปรแกรม ไม่ต้องติดตั้งเพิ่ม)
- **แยกเสียง 6 แทร็ก** ด้วย AI (Demucs `htdemucs_6s`) — ดาวน์โหลดแต่ละแทร็กเป็นไฟล์ได้
- **มิกเซอร์**: ปรับ Volume ทีละแทร็ก, Mute / Solo, ปุ่มลัด "เฉพาะกีตาร์" / "ตัดกีตาร์ (Backing track)"
- **Export Backing Track**: เลือกแทร็กที่จะใส่ (ค่าเริ่มต้น = ทุกแทร็กยกเว้นกีตาร์), เลือกช่วงเวลา (หรือใช้ช่วง A–B), ปรับความเร็ว (เสียงไม่เพี้ยน), ใส่นับนำ 1–2 ห้อง และ/หรือเมโทรนอมตลอดเพลง → ดาวน์โหลด MP3/WAV
- **Slow down** 25%–150% โดยเสียงไม่เพี้ยน (pitch คงเดิม)
- **เมโทรนอม**: ตามจังหวะเพลงอัตโนมัติ (beat tracking) หรือกำหนด BPM เอง, เลือกจังหวะ/ห้อง, นับนำ 1 ห้อง — ช้าลงตามความเร็วเพลง
- **วนซ้ำ A–B** (หรือ Shift+คลิกที่ห้องใน Tab)
- **Tab ซิงก์กับเพลง**: เคอร์เซอร์วิ่งตาม, โน้ตที่กำลังเล่นไฮไลต์, คลิกที่ Tab เพื่อกระโดดไปตรงนั้น, ปรับ offset ซิงก์ได้
- **Export Tab**: `.txt` (ASCII tab), **MusicXML** (เปิดใน MuseScore / Guitar Pro / TuxGuitar ได้), **MIDI**, และ **Sync JSON** (เวลา + สาย + เฟร็ต ทุกโน้ต)
- ถอดโน้ตใหม่จากแทร็กอื่นได้ (เช่นถ้ากีตาร์ไปอยู่ในแทร็ก "อื่นๆ")
- **นำเข้า Tab ที่มีอยู่แล้ว** (แม่นกว่า AI) แล้วซิงก์กับเพลงอัตโนมัติ — รองรับ PDF, Guitar Pro (.gp3/.gp4/.gp5), MusicXML (.musicxml/.mxl), ไฟล์ .txt หรือวางข้อความ Tab

## ติดตั้ง (ครั้งแรกครั้งเดียว)
ต้องมี **Python 3.10 – 3.13** (แนะนำ 3.11/3.12) — ดาวน์โหลดที่ python.org

**Windows**: ดับเบิลคลิก `setup.bat`
**macOS / Linux**: `./setup.sh`

> ครั้งแรกที่แยกเสียง โปรแกรมจะดาวน์โหลดโมเดล AI (~80 MB) อัตโนมัติ

## ใช้งาน
**Windows**: `run.bat`  · **macOS / Linux**: `./run.sh`
แล้วเปิด http://localhost:8000 → ลากไฟล์ MP3 ใส่ **หรือวางลิงก์ YouTube แล้วกด "โหลดเพลง"** → รอประมวลผล → กด "เปิด"

> ถ้าโหลดจาก YouTube แล้วขึ้น error ทั้งที่ลิงก์ถูก (YouTube เปลี่ยนระบบบ่อย) ให้รัน `update.bat` / `./update.sh` เพื่ออัปเดตตัวโหลด
> จำกัดความยาววิดีโอ 20 นาที (เปลี่ยนได้ด้วย `GS_MAX_MINUTES`) · โปรดใช้กับเพลงที่คุณมีสิทธิ์ใช้งาน/เพื่อการซ้อมส่วนตัว

เวลาประมวลผล: เพลง 4 นาทีใช้ประมาณ 3–8 นาทีบน CPU (มีการ์ดจอ NVIDIA จะเร็วกว่ามาก)

### คีย์ลัด
`Space` เล่น/หยุด · `← →` ±5 วิ · `[` `]` ตั้ง A/B · `L` เปิด/ปิดวนซ้ำ · `M` เมโทรนอม · `-` `+` ความเร็ว

## นำเข้า Tab (แทนการถอดด้วย AI)
ในการ์ด Tab กด **📄 นำเข้า Tab จากไฟล์** หรือ **วาง Tab ข้อความ** → โปรแกรมจะสลับไปใช้ "Tab ที่นำเข้า" และ **ซิงก์อัตโนมัติ**
(เทียบโน้ตใน Tab กับเสียงจริงที่ AI ฟังได้ แล้วหาจุดที่ตรงกันที่สุด) — ถ้ายังไม่ตรง กด ±ห้อง / ±จังหวะ

| ไฟล์ | ความแม่น |
|---|---|
| Guitar Pro .gp3/.gp4/.gp5, MusicXML | ⭐⭐⭐ โน้ต + จังหวะ + ท่อนซ้ำ (repeat) ตรงตามไฟล์ |
| PDF ที่ export จากโปรแกรม (Guitar Pro, MuseScore, Songsterr ฯลฯ) | ⭐⭐ สาย/เฟร็ตถูก จังหวะประมาณจากระยะห่างตัวเลข |
| PDF/ข้อความ Tab ตัวอักษร (`e|--0--3--|`) | ⭐⭐ สาย/เฟร็ตถูก จังหวะประมาณ |
| PDF ภาพสแกน / ถ่ายรูป | ❌ ยังไม่รองรับ |

- Guitar Pro 6/7/8 (.gpx/.gp): ใน Guitar Pro ให้ Export เป็น MusicXML หรือ .gp5 ก่อน
- ไฟล์ที่มีหลายแทร็ก เลือกแทร็กกีตาร์ได้ในช่อง "แทร็กในไฟล์"
- Tab จาก PDF/ข้อความไม่มีเครื่องหมายวนซ้ำ ถ้าเพลงมีท่อนซ้ำแต่ Tab เขียนครั้งเดียว ช่วงหลังอาจเลื่อน

## เคล็ดลับให้ Tab แม่นขึ้น
- **กรองโน้ตเบา**: เลื่อนขึ้นเพื่อตัดโน้ตหลอก/เสียงก้อง
- **เลื่อนห้องแรก (downbeat)**: ถ้าเส้นห้องไม่ตรงจังหวะ 1 ของเพลง ลอง +1/+2/+3
- **ซิงก์ Tab (ms)**: ถ้าไฮไลต์มาก่อน/หลังเสียง ให้ปรับตรงนี้
- เมโทรนอมโหมด auto ถ้าจับ BPM เป็นครึ่ง/สองเท่า ให้เปลี่ยนเป็น "กำหนด BPM เอง"
- เพลงที่กีตาร์คลีน/เล่นทีละโน้ต จะถอดได้ดีกว่ากีตาร์ดิสทอร์ชันหรือคอร์ดหนาๆ

> ⚠️ Tab ที่ได้เป็นการถอดอัตโนมัติด้วย AI (Spotify basic-pitch + อัลกอริทึมเลือกสาย/เฟร็ต) ใช้เป็นจุดเริ่มต้นที่ดี
> แต่ไม่แม่น 100% — แนะนำ Export MusicXML ไปแก้ต่อใน MuseScore/TuxGuitar

## ตั้งค่าขั้นสูง (environment variables)
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `GS_PORT` | 8000 | พอร์ต |
| `GS_HOST` | 127.0.0.1 | ตั้ง `0.0.0.0` เพื่อเปิดจากมือถือในวง LAN เดียวกัน |
| `GS_DEVICE` | auto | `cuda` / `cpu` |
| `GS_STEM_FORMAT` | mp3 | `wav` ถ้าต้องการคุณภาพเต็ม |
| `GS_DATA_DIR` | ./data/jobs | ที่เก็บไฟล์ |
| `GS_MAX_MINUTES` | 20 | ความยาวสูงสุดของวิดีโอที่โหลดจาก YouTube |

**ใช้การ์ดจอ NVIDIA**: ติดตั้ง torch แบบ CUDA ตาม https://pytorch.org/get-started/locally/ หลัง setup

## โครงสร้าง
```
app.py          เว็บเซิร์ฟเวอร์ (FastAPI)
processing.py   แยกเสียง (Demucs) + หาจังหวะ (librosa) + ถอดโน้ต (basic-pitch)
tabgen.py       แปลงโน้ต → สาย/เฟร็ต (เลือกตำแหน่งที่มือขยับน้อยที่สุด)
backing.py      สร้างไฟล์ Backing Track (มิกซ์ + ยืดเวลา + count-in)
tabimport.py    อ่าน Tab จาก PDF / Guitar Pro / MusicXML / ข้อความ
static/         หน้าเว็บ (เล่นเพลง, มิกเซอร์, เมโทรนอม, Tab, Export)
```
